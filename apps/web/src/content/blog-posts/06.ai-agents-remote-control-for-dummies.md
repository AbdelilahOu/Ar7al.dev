If you have Twitter, and you are into tech Twitter especially, you might come across many people bragging about how they have the best setup for running their AI agents, with loads of VPSs and agents running on the "cLoUD" all day, and everything is connected, and how they can just control everything from their phone. So today I'm gonna show you how we can do the same thing, but just using your laptop and the phone you already have.

I'm sure there are better tutorials and simpler ways to do this out there, but this is how I chose to do it.

Let's talk about the technologies and software I use for my setup, so we can make this blog a bit longer...

## Claude Code

I don't think this one needs an introduction. Claude Code comes as a CLI and a desktop app, and in this case we only care about the CLI version. Any coding agent that runs in the terminal will do, Claude Code is just my agent of choice. You can also use [opencode](https://opencode.ai), which provides free models to use, if you don't have a subscription of course.

## Herdr

[Herdr](https://herdr.dev) is the app that runs our coding agent, basically it's a terminal made for agents. You can see which agent is working and which one is waiting on you, and they keep running even if you close the app.

I like its simplicity, and it provides remote and multi-machine support. They have a desktop app, which I use, built on GPUI and Rust, and they also have a mobile app, which we will use to talk to our agents.

## Tailscale

[Tailscale](https://tailscale.com) is a VPN that will connect our devices into a private network. I'm not sure it needs more words to describe it, but it will help us put our laptop and phone into one network, even when the phone is on 4G and the laptop is at home.

## Setup

### 1. Tailscale

First thing to do is to create a Tailscale account, download the Tailscale app on our laptop and phone, and sign in to the same account on both. This is the first step, it's that easy really, it's like any other app on your phone.

Since we are now connected to Tailscale, you can see the devices on your network from the dashboard or the mobile app itself. Every device has an address that starts with `100.`, go ahead and copy the one for your laptop, we will need it in a bit.

![The Tailscale app listing the phone and the pc with their addresses](/blog/remote-control/tailscale-devices.png)

### 2. Herdr on the laptop

The Herdr desktop app doesn't need much work. You can just start it directly, open a terminal window (or a space, as they call it), navigate to your project and run the `claude` command.

![Herdr on the desktop with claude running in a space](/blog/remote-control/herdr-desktop.png)

### 3. Herdr on the phone

For the mobile app you will need to connect to your desktop app. Open Herdr on your phone and add a machine, you will have to fill two fields, address and user. The address you already copied from Tailscale, and the user is the one you use for your machine (if you don't know it, run `whoami` in a terminal).

If everything goes well you should see something like this:

![The Herdr mobile app after connecting to the laptop](/blog/remote-control/herdr-add-machine.png)

It didn't go well for me the first time, so here are the issues I ran into when adding the machine.

### Issues I ran into

The first one is that the SSH server wasn't installed on my machine at all, and Herdr uses SSH to talk to your laptop, so I had to install it using this command in PowerShell (open it as administrator):

```powershell
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
```

After that you have to start it and update its config, so the server will auto start when you restart or open your laptop:

```powershell
Start-Service sshd
Set-Service -Name sshd -StartupType Automatic
```

The second one is related to SSH too. Somehow you have to copy the SSH key from the Herdr mobile app and put it into `authorized_keys` in the `.ssh` folder on your laptop, on a new line:

```powershell
notepad $env:USERPROFILE\.ssh\authorized_keys
```

If the user on your laptop is an administrator (mine is), Windows doesn't read that file for you, it reads this one, so I put the key in both to be safe:

```powershell
notepad C:\ProgramData\ssh\administrators_authorized_keys
```

After that you are finally done, you can prompt your agent from your phone and it has access to your machine's folders.
