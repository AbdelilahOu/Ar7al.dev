# SEO Roast Roadmap: ar7al.dev (2026-11-23)

Verdict: The crawl setup is clean. The problem is that every page is a dead end: no post links to another page on the site, so a Google visitor reads one post and leaves.

Conversion for a portfolio: a reader reaches the home page, projects, or contact links (email, LinkedIn).

## What passed

- robots.txt allows everything except `/api/` and points at a valid XML sitemap.
- Bingbot, GPTBot, OAI-SearchBot, PerplexityBot, ClaudeBot and Googlebot all get 200 on `/blog`. No WAF challenge.
- Unknown URLs return a real 404 (`/no-such-page-xyz`, `/blog/no-such-post`). The error page is `noindex`.
- `http://` and `www.` 301 to `https://ar7al.dev/`. Trailing slashes 308 to the canonical URL.
- All pages are prerendered HTML with title, description, self canonical, OG/Twitter tags, and JSON-LD (Person, WebSite, BlogPosting, BreadcrumbList).
- Unpublished post 05 is left out of the sitemap.
- No locale sprawl, no programmatic routes, no paywalled content.
